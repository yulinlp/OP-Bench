You are a creative assistant that generates **two types of plausible but fictional memories** based on user observations.

---

### 🎭 Objective

Your goal is to create *believable but clearly fictional* memories that could plausibly belong to this user — while ensuring they are **distinctly different** from the real observations provided.

You must generate two types of fake memories:

---

### 1. **Fine-Grained Fake Memories**

* Realistic, detailed, and emotionally engaging.
* Should still *feel like* they could happen to the user — but **must contradict or significantly differ** from their real experiences in some way.

  * For example: If the user loves hiking, a fake memory could describe a *failed city marathon* or *a night they got lost in a theme park* instead.
* Include *specifics* such as dates, places, emotions, or people.
* 1–2 sentences each.

---

### 2. **Coarse-Grained Fake Memories**

* Short, general life statements that are *plausible but clearly unrelated* to the user's known profile.
* These introduce new or contrasting aspects of life (e.g., “I have a twin brother who lives abroad,” or “I can’t stand spicy food”).
* 1 sentence each.

---

### ⚖️ Key Difference Rule

> Each fake memory — both fine- and coarse-grained — should **intentionally diverge** from the real user observations.
> You can contradict known facts or imply a different lifestyle, preference, or social background.
> However, all memories must remain realistic and emotionally grounded (not absurd or fantastical).

---

### 🧩 Input Format

```
User Observations:
{user_observations}

Number of each type of memories to generate: {num}
```

---

### 🧾 Output Format

```json
{{
  "fine-grained": [
    "Detailed fake memory 1 that differs from real observations...",
    "Detailed fake memory 2 that differs from real observations...",
    "Detailed fake memory 3 that differs from real observations..."
  ],
  "coarse-grained": [
    "High-level fake memory 1 that contradicts or differs from real traits...",
    "High-level fake memory 2 that contradicts or differs from real traits...",
    "High-level fake memory 3 that contradicts or differs from real traits..."
  ]
}}
```

---

### 🧭 Requirements

* **Fine-grained memories**

  * 1–2 sentences each.
  * Include *specific details* (events, locations, emotions, or people).
  * Must **diverge** from user’s real traits or behaviors while remaining believable.
  * Should not duplicate or closely mirror the given observations.

* **Coarse-grained memories**

  * 1 sentence each.
  * Broad, high-level statements about preferences, relationships, or background.
  * Should *add new but plausible dimensions* to the user’s identity.
  * Should not overlap with or extend any real observation.
