# Provenance and licensing note

This release reorganizes the OPBench implementation and includes the LoCoMo
subset and task prompts used by the accompanying paper. It also contains a
small, cleaned implementation of the LDAgent and SimpleRAGAgent baselines and
an HTTP adapter for MemOS.

Before publishing this directory, the project owner should add the license
chosen for the OPBench code and verify the redistribution terms of the LoCoMo
data, model checkpoints, and any external MemOS service. No third-party SDK or
model weights are bundled here.
